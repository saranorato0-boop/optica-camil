# Óptica Camil — Sitio estático

Este proyecto ya está preparado para publicarse en GitHub Pages.

## Guía rápida

- Para ver la explicación completa, abre [GUIA_PROYECTO.md](GUIA_PROYECTO.md)
- Para cambiar imágenes, revisa la carpeta [imagenes](imagenes)
- Para modificar el diseño, edita [Estilo.css](Estilo.css)

## Archivos principales
- [index.html](index.html): página principal
- [detail.html](detail.html): detalle de productos
- [product.html](product.html): catálogo
- [script.js](script.js): interactividad
- [Estilo.css](Estilo.css): estilos y responsive

## Publicación en GitHub Pages

1. Sube el proyecto a GitHub.
2. Entra a Settings > Pages.
3. Activa Deploy from a branch.
4. Selecciona la rama `main`.
5. Guarda y espera unos minutos.

La URL quedará en el formato:

`https://tu-usuario.github.io/optica-camil/`
